A national statistics site for Japan: population trend since 1920, ageing, age structure, all 47 prefectures in a searchable and sortable table, vital statistics and the economy — real figures from the Statistics Bureau of Japan, the Ministry of Health, Labour and Welfare, and the Cabinet Office. Static files only, no network requests, works on desktop and on a phone.

## Run

Serve `app/` with any static HTTP server and open `index.html`:

```sh
python3 -m http.server --directory app 8080
```
